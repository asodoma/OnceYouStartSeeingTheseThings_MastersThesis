# OnceYouStartSeeingTheseThings_MastersThesis
This repository stores code for the master's thesis “Once You Start Seeing These Things, There is No Going Back”: Narratives of Entry Into Feminism and the Men’s Rights Movement on Reddit (2026)

The jupyter notebooks cover the whole pipeline, from cleaning the raw Reddit data to coding the final testimonies.

The data themselves are not included. They consist of personal accounts posted by Reddit users, and therefore under the GDPR I cannot redistribute them. The research project however can still be reproduced – the r/Feminism and r/MensRights data come from the Pushshift Reddit archives, which contain all posts and comments of a subreddit up to 31 December 2025. With those archives, the notebooks can be run in order to rebuild the dataset and repeat the analysis.
